2. API 差异判断

比较盐型、晶型、供应商、粒径、溶解度、pKa、logP、PPB、清除率等。若 API 本身差异较大，优先判断原料问题。

3. 处方 / 工艺差异判断

比较辅料种类与比例、崩解剂、黏合剂、润滑剂、压片力、包衣、释放类型和多介质溶出。若 f2 低或早期溶出慢，优先判断处方/工艺问题。
